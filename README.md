# AIDD Sudolang-ish Demo (Node.js + ES Modules)

This is a tiny demo project showing how to:

- Use a **sudolang-ish pseudocode DSL** in prompt files
- Generate **pure, functional JavaScript (ES modules + JSDoc)**
- Drive development with **TDD** using Node's built-in test runner
- Keep code **framework-agnostic** and mostly **stateless**

## Requirements

- Node.js 24+ (for the built-in `node:test` module and ES modules)
- Any editor (VS Code recommended)

## Install & Run Tests

```bash
npm test
